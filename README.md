# TASKNEST – SMART TASK MANAGEMENT APP

**Organize Tasks. Stay Productive.**

TASKNEST is a simple and responsive Task Management Web Application built using HTML, CSS, and JavaScript.

## Features

- **Add new tasks**: Quickly create tasks with customizable priority tags.
- **Delete existing tasks**: Remove finished or unwanted tasks with a single click.
- **Prevent empty task submissions**: Real-time form validation with inline alerts and visual feedback.
- **Save tasks using LocalStorage**: Automatically saves your task list into the browser's persistent storage.
- **Restore saved tasks after refreshing the browser**: Safely restores all task items, completion statuses, and priorities upon page reload.
- **Responsive user interface**: Fluid layout crafted for desktop, tablet, and mobile smartphone viewports.
- **Filter views**: Easily filter tasks by *All*, *Active*, and *Completed*.
- **Progress tracking**: Visual progress bar indicating task completion percentage.

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla ES6)
- Browser LocalStorage

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser (Chrome, Firefox, Edge, Safari).
4. Start adding and managing tasks.
